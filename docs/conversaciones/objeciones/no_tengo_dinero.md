# Objeciones — "No Tengo Dinero"

# Objetivo
Responder con empatía real a una limitación económica genuina, sin presionar ni hacer sentir mal al cliente, dejando la puerta abierta para el futuro.

# Momento del embudo
Objeciones (después de [Recomendación](../recomendacion/index.md), antes de [Cierre](../cierre/index.md))

# Perfil de cliente relacionado
Transversal — aplica a cualquier perfil de [`docs/clientes/`](../../clientes/README.md).

# Productos relacionados
Depende de la conversación previa; considerar productos de menor ticket como alternativa (ej. [TéDivina](../../productos/01-control-de-peso/tedivina.md), [Reishi Soap](../../productos/12-cuidado-personal.md#reishi-soap)).

# Contexto
El cliente expresa directamente que no cuenta con el dinero en este momento, a diferencia de "está caro" (percepción de valor) — aquí es una limitación real de presupuesto.

# Conversación ejemplo

Cliente:
La verdad ahorita no tengo el dinero, ando corto/a este mes.

Asesor:
Te entiendo perfectamente, no te preocupes 🙌 No hay ninguna prisa. ¿Te gustaría que te escriba más adelante, o prefieres tú avisarme cuando sea un buen momento para ti?

Cliente:
Mejor escríbeme tú en un tiempo, así no se me olvida.

Asesor:
Listo, así quedamos. Mientras tanto, si tienes alguna duda sobre el producto o quieres que te cuente de alguna opción más accesible para cuando puedas, aquí estoy sin compromiso.

# Variantes de respuesta

- Si el cliente pregunta si hay algo más económico: ofrecer una alternativa de menor ticket dentro del mismo perfil de necesidad, sin insistir en el producto original.
- Si el cliente se disculpa o se ve incómodo/a: normalizar la situación ("no pasa nada, de verdad, a todos nos pasa") para que no sienta presión ni vergüenza.

# Qué hacer después
Programar un seguimiento respetuoso, generalmente [`seguimiento/seguimiento_15dias.md`](../seguimiento/seguimiento_15dias.md) o [`seguimiento/seguimiento_30dias.md`](../seguimiento/seguimiento_30dias.md), según lo que el cliente haya indicado.

# Qué NO decir
- No ofrecer "financiamiento" o facilidades de pago que no existan realmente o no estén confirmadas.
- No insistir en el mismo producto de mayor precio — mejor ofrecer una opción accesible o simplemente esperar.
- No hacer sentir mal al cliente ni minimizar su situación.

# Notas comerciales
*(Recomendación comercial, no médica)* Esta objeción, bien manejada, genera clientes muy leales a futuro — el cliente recuerda quién no lo presionó cuando no podía comprar. El seguimiento respetuoso aquí vale más que el cierre inmediato.
