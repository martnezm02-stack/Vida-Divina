# Objeciones

[🏠 Índice general de Conversaciones](../README.md)

Respuestas a dudas y resistencias comunes, **sin usar técnicas de presión** (sin urgencias falsas, sin culpa, sin insistencia tras un "no"). Se priorizaron las objeciones más transversales (aplican a casi cualquier perfil/producto) más la objeción médica, priorizada por riesgo.

> Cada objeción construida tiene también una ficha de análisis (por qué surge, cómo abordarla estratégicamente) en [`docs/objeciones/`](../../objeciones/README.md). Este índice enlaza el diálogo; `docs/objeciones/` enlaza el razonamiento detrás.
