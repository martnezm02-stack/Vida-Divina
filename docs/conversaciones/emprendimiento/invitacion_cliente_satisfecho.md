# Emprendimiento — Invitación a Cliente Satisfecho

# Objetivo
Abrir la conversación sobre la oportunidad de negocio con un cliente que ya tuvo una buena experiencia de producto, usando esa experiencia como punto de partida genuino.

# Momento del embudo
Emprendimiento (rama paralela, generalmente después de [Postventa](../postventa/index.md))

# Perfil de cliente relacionado
[Emprendimiento](../../clientes/emprendimiento.md)

# Productos relacionados
No aplica producto específico — esta conversación es sobre la oportunidad de negocio, apoyada en la experiencia de producto que el cliente ya tuvo.

# Contexto
El cliente ya confirmó estar satisfecho con su producto (idealmente después de [`postventa/verificar_satisfaccion.md`](../postventa/verificar_satisfaccion.md)) y ya recomendó el producto de forma espontánea a alguien más.

# Conversación ejemplo

Cliente:
Sí, la verdad estoy muy contenta, se lo voy a recomendar a mi hermana.

Asesor:
Qué bueno 😊 Oye, ya que lo vas a recomendar de todas formas, ¿te gustaría saber cómo convertir esas recomendaciones en un ingreso extra para ti? Te cuento sin compromiso, solo si te da curiosidad.

Cliente:
Uy, la verdad sí me interesaría saber más.

Asesor:
Perfecto, con gusto te comparto cómo funciona la parte de negocio — dame un momento para explicarte bien, porque hay varios detalles importantes que quiero que conozcas con calma.

# Variantes de respuesta

- Si el cliente dice que no le interesa: aceptar sin insistir, mantenerlo únicamente como cliente de producto (ver [`objeciones/index.md`](../objeciones/index.md) para "no quiero emprender", pendiente de construir con el mismo tono de respeto).
- Si el cliente pregunta directamente cuánto se puede ganar: **no improvisar una cifra** — remitir al material oficial de negocio ("eso te lo explico con el material oficial, para darte información exacta y no un estimado mío").

# Qué hacer después
Si hay interés genuino, continuar la conversación apoyándose en material oficial de negocio (fuera del alcance de este catálogo de producto) e involucrar, si es posible, a un patrocinador con más experiencia.

# Qué NO decir
- No inventar cifras de ingreso, ni siquiera como "ejemplo aproximado".
- No presentar la oportunidad como garantía de éxito económico.
- No insistir si el cliente ya dijo que no le interesa el tema de negocio.

# Notas comerciales
*(Recomendación comercial, no médica)* El mejor momento para esta invitación es cuando el cliente ya está recomendando el producto por su cuenta — en ese punto, la conversación de negocio se siente como una oportunidad natural, no como una venta forzada.
