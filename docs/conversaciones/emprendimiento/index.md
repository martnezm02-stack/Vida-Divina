# Emprendimiento

[🏠 Índice general de Conversaciones](../README.md)

Conversaciones sobre la oportunidad de negocio (afiliación), basadas en el perfil [Emprendimiento](../../clientes/emprendimiento.md) de `docs/clientes/`.

> **Importante:** el catálogo analizado (`catalogo 2026.pdf`) es un catálogo de producto, no un plan de compensación. Ningún archivo de esta carpeta inventa cifras de ingresos, requisitos de afiliación o estructura de comisiones — todo eso debe completarse con el material oficial de negocio de Vida Divina.
