# Cierre — Confirmación de Envío

# Objetivo
Informar al cliente que su pedido fue despachado, generando tranquilidad y expectativa positiva.

# Momento del embudo
Cierre (después de [Explicación de Pago](./explicacion_pago.md))

# Perfil de cliente relacionado
Transversal.

# Productos relacionados
Los del pedido confirmado.

# Contexto
El pago fue confirmado y el pedido está listo para enviarse o ya fue enviado.

# Conversación ejemplo

Asesor:
¡Ya está en camino tu pedido! 📦 [Detalle real: número de guía, tiempo estimado, o método de entrega que uses]. Cualquier cosa que necesites mientras te llega, aquí estoy.

Cliente:
Perfecto, gracias por avisar.

Asesor:
Con gusto 😊 En cuanto te llegue, si quieres me cuentas qué te pareció.

# Variantes de respuesta

- Si la entrega es en persona (no envío formal): ajustar el mensaje a coordinar lugar y hora en vez de número de guía.
- Si hay algún retraso: comunicarlo proactivamente y con honestidad, sin esperar a que el cliente pregunte.

# Qué hacer después
Programar el primer contacto de [`postventa/verificar_satisfaccion.md`](../postventa/verificar_satisfaccion.md) para cuando el cliente ya haya recibido y probado el producto.

# Qué NO decir
- No dar tiempos de entrega que no se puedan cumplir realmente.
- No dejar de avisar si hay un retraso — el silencio genera más desconfianza que informar honestamente.

# Notas comerciales
*(Recomendación comercial, no médica)* Los detalles logísticos de envío (mensajería, tiempos, costos) no están definidos en el catálogo de producto — deben completarse con la operación real del negocio.
