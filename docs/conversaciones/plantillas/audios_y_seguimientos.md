# Plantillas — Audios y Aperturas de Seguimiento

# Objetivo
Dar guía sobre el uso de notas de voz en WhatsApp, y ofrecer aperturas genéricas reutilizables para cualquier mensaje de seguimiento (complementan los guiones específicos por tiempo en [`seguimiento/`](../seguimiento/index.md)).

# Cuándo usar un audio en vez de texto
- Para explicaciones largas donde el tono cálido de la voz ayuda (por ejemplo, resolver una objeción sensible como en [`objeciones/mi_medico_no_me_deja.md`](../objeciones/mi_medico_no_me_deja.md)).
- Cuando el cliente mismo ha enviado audios — igualar el formato de comunicación que él o ella prefiere.
- Para dar seguimiento con un tono más personal, no mecánico.

**Guía de contenido de un audio de seguimiento (30-45 segundos aprox.):**
1. Saludo con el nombre del cliente.
2. Una frase que recuerde brevemente el tema pendiente, sin sonar a reclamo.
3. Una pregunta abierta y genuina.
4. Cierre cálido, sin presión.

## Cuándo NO usar audio
- Si el cliente solo ha escrito texto y nunca audios — respetar su canal preferido.
- Para primer contacto — un audio de alguien desconocido puede sentirse invasivo; mejor empezar con texto.

# Aperturas genéricas reutilizables para seguimiento
Estas frases pueden insertarse en cualquier mensaje de [`seguimiento/`](../seguimiento/index.md) como gancho inicial:

- "Iba pasando por aquí y me acordé de ti 😊"
- "Quería saber cómo has estado, más allá de lo que platicamos."
- "No quiero ser invasivo/a, solo quería confirmar que sigues bien."
- "Se me ocurrió algo que capaz te interesa, ¿tienes un momento?"

# Qué NO hacer
- No mandar audios largos (más de 1 minuto) como primer seguimiento — pocas personas los escuchan completos.
- No usar audio para insistir en una venta — el tono de voz puede sentirse más presionante que el texto si no se cuida bien.

# Notas comerciales
*(Recomendación comercial, no médica)* El audio humaniza la conversación, pero solo si se usa con el mismo respeto por el tiempo del cliente que un mensaje de texto — no es una herramienta para "hablar más" sino para conectar mejor.
