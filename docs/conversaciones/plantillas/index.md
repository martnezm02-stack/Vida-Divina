# Plantillas

[🏠 Índice general de Conversaciones](../README.md)

Mensajes cortos y reutilizables — **no son conversaciones completas**, sino piezas sueltas que se insertan dentro de cualquier conversación de las otras carpetas. Formato más ligero que el resto del módulo: Objetivo, Cuándo usar, Ejemplos, Qué NO hacer, Notas comerciales.

Se fusionaron las 8 categorías solicitadas en 5 archivos por afinidad temática.

| [confirmaciones.md](./confirmaciones.md) | Confirmaciones (pedido, datos, entendido) |
| [mensajes_cortos_y_largos.md](./mensajes_cortos_y_largos.md) | Guía de cuándo usar mensaje corto vs. largo, con ejemplos de cada uno |
