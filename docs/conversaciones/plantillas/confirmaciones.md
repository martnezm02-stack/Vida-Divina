# Plantillas — Confirmaciones

# Objetivo
Ofrecer frases cortas para confirmar que algo quedó entendido, acordado o recibido, dando claridad a la conversación.

# Cuándo usar
Después de que el cliente da un dato (dirección, nombre, decisión), o para confirmar que un mensaje fue leído/entendido. Para la confirmación específica de un pedido completo, ver el escenario completo en [`cierre/confirmacion_pedido.md`](../cierre/confirmacion_pedido.md).

# Ejemplos

- "¡Perfecto, quedó anotado! ✅"
- "Listo, ya lo tengo confirmado."
- "Entendido, gracias por confirmarme."
- "Genial, con esos datos ya podemos avanzar."
- "Todo claro de mi parte, ¿alguna otra duda?"

# Qué NO hacer
- No confirmar datos importantes (dirección, cantidad, producto) sin repetirlos explícitamente — un simple "ok" no es suficiente para pedidos.
- No dar por hecho que el cliente confirmó algo que en realidad quedó ambiguo.

# Notas comerciales
*(Recomendación comercial, no médica)* Confirmar explícitamente (repitiendo el dato, no solo diciendo "ok") reduce errores de pedido y da una imagen de atención profesional.
