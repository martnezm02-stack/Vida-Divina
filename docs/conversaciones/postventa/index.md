# Postventa

[🏠 Índice general de Conversaciones](../README.md)

Conversaciones para después de que el cliente ya recibió su pedido. Se priorizaron los 3 escenarios de mayor valor comercial: confirmar satisfacción, vender productos complementarios, y pedir testimonio.

## Construidos

| Escenario | Archivo | Valor comercial |
|---|---|---|
| Verificar satisfacción | [verificar_satisfaccion.md](./verificar_satisfaccion.md) | Retención y detección temprana de problemas |
| Recomendar complementarios | [recomendar_complementarios.md](./recomendar_complementarios.md) | Venta cruzada (recompra) |
| Solicitar testimonio | [solicitar_testimonio.md](./solicitar_testimonio.md) | Material para marketing y nuevas ventas |

## Pendientes (estructura lista, no construidos aún)

| Escenario | Nota para cuando se construya |
|---|---|

| Solicitar recomendación (referidos) | Similar a `solicitar_testimonio.md` pero pidiendo un contacto en vez de una reseña — se puede construir reutilizando esa misma estructura. |
