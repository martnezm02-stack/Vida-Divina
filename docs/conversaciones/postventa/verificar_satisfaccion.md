# Postventa — Verificar Satisfacción

# Objetivo
Confirmar que el cliente recibió el producto y está teniendo una buena experiencia, detectando a tiempo cualquier inconformidad.

# Momento del embudo
Postventa (después de [Cierre](../cierre/index.md), unos días después de la entrega)

# Perfil de cliente relacionado
Transversal — aplica a cualquier perfil de [`docs/clientes/`](../../clientes/README.md).

# Productos relacionados
El producto entregado al cliente.

# Contexto
Ya pasaron unos días desde que el cliente recibió su pedido; es momento de hacer seguimiento de la experiencia, no de vender algo nuevo todavía.

# Conversación ejemplo

Asesor:
¡Hola [Nombre]! ¿Cómo te fue con el [producto]? ¿Ya lo empezaste a usar?

Cliente:
Sí, ya llevo unos días tomándolo.

Asesor:
¡Qué bien! ¿Cómo te has sentido hasta ahora? Cuéntame sin pena, sea lo que sea, para poder ayudarte mejor.

# Variantes de respuesta

- Si el cliente reporta buena experiencia: agradecer y avanzar hacia [`recomendar_complementarios.md`](./recomendar_complementarios.md) o [`solicitar_testimonio.md`](./solicitar_testimonio.md).
- Si el cliente reporta una experiencia neutra o negativa: escuchar primero sin justificar el producto de inmediato; preguntar detalles (¿cómo lo está usando?, ¿desde cuándo?) antes de sacar conclusiones.
- Si el cliente reporta algo que suene a reacción adversa: **no minimizar** — recomendar suspender el uso y consultar a un profesional de salud si es necesario, priorizando su bienestar sobre la venta.

# Qué hacer después
Según la respuesta: [`recomendar_complementarios.md`](./recomendar_complementarios.md), [`solicitar_testimonio.md`](./solicitar_testimonio.md), o escalar cualquier inquietud de salud a un canal apropiado (nunca minimizarla en el chat).

# Qué NO decir
- No presionar por una venta nueva antes de confirmar que la experiencia con el producto actual fue positiva.
- No descartar una queja o duda del cliente para "seguir vendiendo".

# Notas comerciales
*(Recomendación comercial, no médica)* Este mensaje es el que más impacta la retención a largo plazo — un cliente que siente seguimiento genuino después de la compra es mucho más propenso a recomprar y recomendar.
