# Seguimiento — 7 Días

# Objetivo
Hacer un check-in respetuoso una semana después, dando al cliente una salida cómoda si ya no está interesado, sin insistir.

# Momento del embudo
Seguimiento

# Perfil de cliente relacionado
Transversal.

# Productos relacionados
Los mencionados en la conversación previa con este cliente específico.

# Contexto
Pasó una semana sin respuesta o sin decisión. Es momento de confirmar si sigue interesado, dejando espacio para un "no" sin fricción.

# Conversación ejemplo

Asesor:
¡Hola [Nombre]! Solo pasaba a saludar 😊 ¿Sigues interesado/a en lo del [producto], o prefieres que lo dejemos por ahora? Cualquiera de las dos está perfecto, solo para no seguirte escribiendo si ya no es el momento.

Cliente:
Sí me interesa, solo he andado ocupado/a.

Asesor:
No hay problema, lo entiendo total 🙌 Cuando tengas un momento, seguimos platicando. Aquí quedo pendiente.

# Variantes de respuesta

- Si el cliente responde que ya no le interesa: agradecer con calidez, sin insistir, y cerrar la conversación de forma positiva (dejar la puerta abierta a futuro).
- Si el cliente confirma interés pero sigue sin decidir: preguntar puntualmente qué le falta para decidir (puede revelar una objeción no dicha aún).

# Qué hacer después
Según la respuesta: [`cierre/cierre_venta.md`](../cierre/cierre_venta.md) si hay decisión, [`seguimiento_15dias.md`](./seguimiento_15dias.md) si pide más tiempo, o cerrar la conversación con respeto si dice que no.

# Qué NO decir
- No hacer sentir mal al cliente por no haber respondido antes.
- No insistir una segunda vez en la misma semana si ya se envió este mensaje.

# Notas comerciales
*(Recomendación comercial, no médica)* Dar una salida clara y cómoda ("o prefieres que lo dejemos por ahora") reduce la sensación de presión y, paradójicamente, suele aumentar la tasa de respuesta genuina.
