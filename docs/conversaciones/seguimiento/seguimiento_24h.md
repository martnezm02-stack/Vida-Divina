# Seguimiento — 24 Horas

# Objetivo
Retomar contacto un día después de una conversación sin cierre, mientras el interés del cliente sigue "fresco", resolviendo dudas pendientes.

# Momento del embudo
Seguimiento (rama paralela desde [Objeciones](../objeciones/index.md) o [Recomendación](../recomendacion/index.md) sin cierre)

# Perfil de cliente relacionado
Transversal — aplica a cualquier perfil de [`docs/clientes/`](../../clientes/README.md).

# Productos relacionados
Los mencionados en la conversación previa con este cliente específico.

# Contexto
Pasaron aproximadamente 24 horas desde la última conversación, en la que el cliente mostró interés pero no cerró ni dio una razón clara para no seguir.

# Conversación ejemplo

Asesor:
¡Hola [Nombre]! 😊 Quería saber si te quedó alguna duda de lo que hablamos ayer sobre el [producto]. Cualquier cosa, aquí estoy.

Cliente:
Ah hola, la verdad no he tenido tiempo de pensarlo bien.

Asesor:
Tranquilo/a, no hay ninguna prisa 🙌 Solo quería confirmar que no quedó nada sin resolver de mi parte. Cuando gustes retomamos.

# Variantes de respuesta

- Si el cliente no responde en 24h: no insistir de nuevo hasta el siguiente punto de contacto ([`seguimiento_3dias.md`](./seguimiento_3dias.md)).
- Si el cliente pregunta algo nuevo: responder puntualmente y, si aplica, redirigir a la ficha de objeción correspondiente en [`objeciones/`](../objeciones/index.md).

# Qué hacer después
Si hay respuesta positiva, avanzar a [`cierre/cierre_venta.md`](../cierre/cierre_venta.md). Si no hay respuesta, esperar y usar [`seguimiento_3dias.md`](./seguimiento_3dias.md).

# Qué NO decir
- No repetir la misma recomendación de producto palabra por palabra — solo confirmar disponibilidad para dudas.
- No usar frases de presión ("¿ya decidiste?", "se acaba la promoción").

# Notas comerciales
*(Recomendación comercial, no médica)* El seguimiento de 24h funciona mejor como "puerta abierta" que como recordatorio de venta — el objetivo es que el cliente sienta acompañamiento, no seguimiento comercial agresivo.
