# Recomendación — Sistema Inmunológico

# Objetivo
Recomendar un producto de hongos medicinales adecuado al nivel de familiaridad del cliente con este tipo de suplementos (principiante vs. ya conoce el tema).

# Momento del embudo
Recomendación (después de [Descubrimiento](../descubrimiento/index.md))

# Perfil de cliente relacionado
[Sistema Inmunológico](../../clientes/sistema_inmunologico.md)

# Productos relacionados
- [Chaga Capsules](../../productos/03-longevidad-bienestar/chaga-capsules.md)
- [Reishi Capsules](../../productos/03-longevidad-bienestar/reishi-capsules.md)
- [Time Capsules](../../productos/03-longevidad-bienestar/time-capsules.md)

# Contexto
El cliente mencionó en descubrimiento que se enferma con frecuencia en cambios de clima y nunca ha probado hongos medicinales.

# Conversación ejemplo

Cliente:
Cada cambio de clima me enfermo, quiero subir mis defensas pero nunca he tomado nada de hongos ni eso.

Asesor:
Perfecto punto de partida 🙌 Te recomendaría el Chaga Capsules — es, de hecho, el producto que la marca describe como su "producto estrella" para el sistema inmunológico. Es 100% Chaga siberiano, fácil de tomar en cápsulas.

Cliente:
¿Y el Reishi es diferente?

Asesor:
Son complementarios — el Reishi es el ingrediente base de casi toda la marca, también apoya el sistema inmune y además ayuda con el estrés. Si quieres ir a la fija con un solo producto muy representativo, el Time Capsules combina Chaga, Reishi y Cordyceps en una sola fórmula, para no tener que elegir entre los tres.

# Variantes de respuesta

- Si el cliente quiere "ir a lo seguro" con un solo producto: [Time Capsules](../../productos/03-longevidad-bienestar/time-capsules.md), ya que combina los 3 hongos principales.
- Si el cliente ya conoce hongos medicinales y quiere variar: mencionar los extractos individuales en [`docs/productos/11-extractos-hongos/`](../../productos/11-extractos-hongos/index.md) (Maitake, Shiitake, Turkey Tail, etc.) como opción de exploración.
- Si el interés es más respiratorio específicamente: [CordyCS-4 Capsules](../../productos/03-longevidad-bienestar/cordycs-4-capsules.md).

# Qué hacer después
Avanzar a [`cierre/cierre_venta.md`](../cierre/cierre_venta.md). Dado que este es un objetivo de mediano-largo plazo, preparar al cliente para un [seguimiento a las 4 semanas](../seguimiento/seguimiento_30dias.md) en vez de uno inmediato.

# Qué NO decir
- No prometer que el cliente "no se va a enfermar más" — el catálogo habla de apoyo al sistema inmunológico, no de inmunidad garantizada.
- No abrumar a un cliente principiante presentando los 9 extractos de hongos de una sola vez.

# Notas comerciales
*(Recomendación comercial, no médica)* Con clientes nuevos en el tema de hongos medicinales, conviene empezar con 1 producto (Chaga o Time) y dejar los extractos individuales como venta futura en [Postventa](../postventa/index.md), una vez haya confianza establecida.
