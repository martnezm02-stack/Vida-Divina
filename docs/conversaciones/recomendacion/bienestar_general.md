# Recomendación — Bienestar General

# Objetivo
Recomendar un producto de entrada, de bajo compromiso, a un cliente que no tiene una necesidad puntual identificada.

# Momento del embudo
Recomendación (después de [Descubrimiento](../descubrimiento/index.md))

# Perfil de cliente relacionado
[Bienestar General](../../clientes/bienestar_general.md)

# Productos relacionados
- [TéDivina](../../productos/01-control-de-peso/tedivina.md)
- [Reishi Capsules](../../productos/03-longevidad-bienestar/reishi-capsules.md)
- [Café Divina Black](../../productos/02-cafe-divina/black.md)

# Contexto
El cliente, en descubrimiento, dio una respuesta vaga tipo "quiero cuidarme más" sin mencionar un problema puntual.

# Conversación ejemplo

Cliente:
La verdad no tengo un problema puntual, solo quiero empezar a cuidarme más.

Asesor:
Me encanta esa actitud 🙌 Para empezar sin complicarte, te recomendaría el TéDivina — es nuestro producto más vendido, un té que ayuda a limpiar el cuerpo y te da una base para cualquier cosa que quieras trabajar después (energía, peso, lo que sea). Es bien fácil de tomar, hasta un niño lo puede tomar de lo natural que es.

Cliente:
Suena bien, ¿y qué más tiene?

Asesor:
Contiene hierbas como cardo bendito, malvavisco, chaga y jengibre, entre otras — apoya la desintoxicación natural y mejora el tránsito intestinal. Si te gusta el café, también podríamos empezar por ahí: el Café Divina Black tiene Reishi, que es el ingrediente insignia de la marca, y lo tomas igual que tu café de siempre.

# Variantes de respuesta

- Si el cliente ya toma café a diario: liderar con [Café Divina Black](../../productos/02-cafe-divina/black.md) o [Latte](../../productos/02-cafe-divina/latte.md) en vez de TéDivina — es un cambio de hábito más fácil.
- Si el cliente muestra curiosidad por "lo natural"/hongos medicinales: liderar con [Reishi Capsules](../../productos/03-longevidad-bienestar/reishi-capsules.md), contando brevemente la historia del Reishi como base de la marca.

# Qué hacer después
Si el cliente muestra interés, avanzar a [`cierre/cierre_venta.md`](../cierre/cierre_venta.md). Si pide tiempo para pensarlo, pasar a [`seguimiento/seguimiento_24h.md`](../seguimiento/seguimiento_24h.md).

# Qué NO decir
- No recomendar 4-5 productos a la vez — un cliente sin necesidad clara se abruma más fácil con muchas opciones.
- No prometer resultados específicos o tiempos exactos.

# Notas comerciales
*(Recomendación comercial, no médica)* Con este perfil, el objetivo no es la venta más grande posible, sino generar una primera experiencia positiva que abra la puerta a compras futuras más específicas.
