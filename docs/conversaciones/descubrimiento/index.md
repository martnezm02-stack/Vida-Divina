# Descubrimiento

[🏠 Índice general de Conversaciones](../README.md)

Este es el paso más importante del embudo: identificar a qué perfil de [`docs/clientes/`](../../clientes/README.md) pertenece el cliente **antes** de recomendar cualquier producto. A diferencia de las demás carpetas, Descubrimiento es intencionalmente genérico — las mismas 2-3 preguntas sirven para encaminar a casi cualquier cliente, sin importar el canal de entrada.

> **Regla de oro de esta carpeta:** nunca recomendar un producto durante el descubrimiento. El objetivo único es entender, no vender todavía.

## Construidos

| Archivo | Para qué sirve |
|---|---|
| [Preguntas generales](./preguntas_generales.md) | Guion universal de 3-4 preguntas para descubrir la necesidad del cliente, sin importar el canal de entrada |
| [Señales por perfil](./senales_por_perfil.md) | Tabla de referencia: qué suele decir el cliente → a qué perfil de `docs/clientes/` corresponde |

## Pendientes (estructura lista, no construidos aún)

Esta carpeta se considera con cobertura suficiente para la mayoría de casos con solo estos 2 archivos, dado que el descubrimiento es genérico por diseño. Si en el futuro se detectan patrones de descubrimiento muy distintos por canal (por ejemplo, un guion de descubrimiento específico para clientes que llegan ya interesados en el negocio), agregar aquí siguiendo el mismo formato.
