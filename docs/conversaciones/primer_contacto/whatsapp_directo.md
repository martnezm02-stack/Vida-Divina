# Primer Contacto — WhatsApp Directo (sin contexto previo)

# Objetivo
Responder a un contacto que escribe por WhatsApp sin que se sepa aún de dónde salió el número ni qué busca, abriendo la conversación de forma natural.

# Momento del embudo
Primer Contacto → (siguiente paso: [Descubrimiento](../descubrimiento/preguntas_generales.md))

# Perfil de cliente relacionado
Aún no identificado — este es el escenario más genérico de entrada, útil como catch-all cuando no aplica ninguno de los otros escenarios de primer contacto.

# Productos relacionados
Ninguno todavía.

# Contexto
El número de WhatsApp del asesor está guardado (tarjeta de presentación, grupo, evento) y el cliente escribe directamente, muchas veces con un saludo simple.

# Conversación ejemplo

Cliente:
Hola

Asesor:
¡Hola! 😊 Buenas, un gusto. Soy [Nombre], trabajo con Vida Divina. ¿En qué te puedo ayudar hoy?

Cliente:
Vi que manejas productos naturales, quería saber más.

Asesor:
Claro que sí 🙌 Manejamos varias líneas: control de peso, energía, bienestar general, cuidado de la piel, entre otras. Para no mandarte información de más, cuéntame: ¿hay algo puntual que te gustaría mejorar o cuidar en este momento?

# Variantes de respuesta

- Si el cliente solo saluda y no dice nada más tras la primera respuesta: esperar su respuesta antes de seguir preguntando; no bombardear con mensajes seguidos.
- Si el cliente pregunta directo "¿qué venden?": responder con 2-3 categorías amplias (no la lista completa de 66 productos) e invitar a precisar la necesidad.

# Qué hacer después
Continuar con [`descubrimiento/preguntas_generales.md`](../descubrimiento/preguntas_generales.md).

# Qué NO decir
- No enviar un catálogo completo o lista de precios como primer mensaje.
- No presionar preguntando "¿vas a comprar?" en los primeros mensajes.
- No sonar a mensaje copiado y pegado masivo — personalizar aunque sea mínimamente.

# Notas comerciales
*(Recomendación comercial, no médica)* Este es el escenario más común y menos "calificado" — conviene invertir el primer intercambio en entender de dónde llegó el contacto (¿anuncio?, ¿alguien lo invitó?, ¿grupo?) porque eso determina qué tan "caliente" está el prospecto.
