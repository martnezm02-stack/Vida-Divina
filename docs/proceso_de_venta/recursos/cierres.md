## Té Divina — audio de cierre específico

El Té Divina tiene un audio específico de cierre, utilizado después de enviar el precio del Té Divina.

El audio:

- refuerza que no es simplemente un té;
- presenta el producto como tratamiento completo de 42 días;
- explica el costo diario;
- refuerza el valor del tratamiento;
- comunica pago anticipado;
- comunica que existe asesoría durante el tratamiento;
- termina buscando la decisión de compra.

**Pregunta final:**

> "¿Tiene alguna pregunta o le gustaría comenzar con uno de los paquetes?"

**Fuente:** `SPRINT_5_PROCESO_COMERCIAL.md` §9.1.

## Otros productos — cierre textual

No se dispone actualmente de un audio de cierre específico para cada producto. Para otros productos se utiliza cierre por texto:

> "¿Tiene alguna otra pregunta o le gustaría comenzar con algunos de los paquetes?"

**Fuente:** `SPRINT_5_PROCESO_COMERCIAL.md` §9.2.

## Nota de cobertura

El audio de cierre actualmente documentado para este proceso corresponde al Té Divina. Para los demás productos se utiliza el cierre textual indicado en este documento. No se agregan otros audios de cierre que no hayan sido proporcionados o documentados.
