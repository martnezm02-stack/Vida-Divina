## Principio de este sub-módulo

Ningún archivo de este sub-módulo inventa contenido. Donde `SPRINT_5_PROCESO_COMERCIAL.md` ya documenta el recurso con contenido real (texto citable), se transcribe tal cual, citando la sección exacta. Donde no existe ese contenido, el archivo correspondiente deja la estructura/indexación lista y marca explícitamente **PENDIENTE** — nunca se rellena con una suposición.
