# Recurso: Respuestas Rápidas de Pago

[⬅ Recursos](./README.md) · [🏠 Índice de Proceso de Venta](../README.md)

> Derivado de [`SPRINT_5_PROCESO_COMERCIAL.md`](../SPRINT_5_PROCESO_COMERCIAL.md) §11, que permanece como fuente de verdad del proceso comercial real de Vida Divina.

## Descripción

Cuando el cliente solicita cuenta para transferencia (ej. "Pásame la cuenta para transferir"), se envían los datos de cuenta/medio de pago mediante las respuestas rápidas disponibles. También existe un link de pago disponible como respuesta rápida.

## Estructura

| Respuesta rápida | Cuándo se usa | Contenido literal | Estado |
|---|---|---|---|
| Cuenta/transferencia | Cliente pide datos para transferir | — | **PENDIENTE** — Sprint 5 confirma que existe, no transcribe el texto exacto |
| Link de pago | Cliente indica cantidad/producto y se procede al cierre | — | **PENDIENTE** — Sprint 5 confirma que existe, no transcribe el texto exacto |

No se inventa ningún texto de respuesta rápida ni ningún dato de cuenta.

## Fuente

`SPRINT_5_PROCESO_COMERCIAL.md` §11.
