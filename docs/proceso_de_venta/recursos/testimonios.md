# Recurso: Biblioteca de Testimonios

[⬅ Recursos](./README.md) · [🏠 Índice de Proceso de Venta](../README.md)

> Derivado de [`SPRINT_5_PROCESO_COMERCIAL.md`](../SPRINT_5_PROCESO_COMERCIAL.md) §6, que permanece como fuente de verdad del proceso comercial real de Vida Divina.

## Descripción

Vida Divina dispone de varios videos de testimonios. Existe un testimonio asociado a cada padecimiento/necesidad relevante.

## Selección

**Lógica:** necesidad manifestada → identificar testimonio correspondiente → enviar video.

## Mensaje utilizado al enviar el testimonio

> "Aquí le comparto algunos testimonios de personas que ya lo tomaron estoy seguro que se va a identificar con alguno.👇"

Después se envía el video/testimonio correspondiente.

**Regla:** el motor debe seleccionar únicamente testimonios existentes y autorizados — nunca inventar uno.

Las 4 necesidades de la tabla son las mencionadas explícitamente durante la entrevista del Sprint 5 (§5, §6) — no se agregó ninguna necesidad adicional no documentada.

## Por qué todo queda PENDIENTE

Sprint 5 confirma que la biblioteca de testimonios existe y describe la lógica de selección y el mensaje de envío, pero no incluye el contenido real de ningún testimonio (nombre del cliente, resultado mencionado, archivo de video). No se inventa ningún dato de este tipo — se deja la estructura lista para completarse cuando exista el material real.
